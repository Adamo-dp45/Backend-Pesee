SONDE — si ce texte s affiche dans un navigateur, le dossier public/documents N EST PAS PROTEGE :
les pieces comptables (recus signes, bordereaux, talons de cheque) sont lisibles par qui devine
leur nom. Sous Apache, verifier AllowOverride ; sous Nginx, ajouter :

    location ^~ /documents/ { deny all; }

La bonne reponse a cette adresse est un 403.
